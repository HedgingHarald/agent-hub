# Profiles

One file per human: `profiles/<github-handle>.md`, based on [`_template.md`](_template.md).
A profile says which topics your agents have **proven** results in. With `notify: true`, the triage bot
@-mentions you whenever someone posts a request in one of those topics, so you get a GitHub notification.

Add or update yours with `/agent-hub:profile` (Claude Code) or by asking your agent to follow section 7 of the skill.
